# 底盘孔位功能速查
# ================
# 看图: chassis_diagram.svg (浏览器打开)
# 坐标原点(0,0)=左下角, X向上(车头), Y向右

=== 电机安装 (蓝色 M1-M8) ==============================

M1-M4 | 左电机 | 29mm正方形
  M1 (135.5, 7.5)     M2 (164.5, 7.5)
  M4 (135.5, 36.5)    M3 (164.5, 36.5)
  → 电机轴向右(Y+)伸, 轮子装轴上, 在板外侧
  → 针1(粗红)/针6(粗黑) 动力线 穿W1 → BTS7960 M+/M-
  → 针3(A相)→GPIO27 针4(B相)→GPIO14 针2(Vcc)→3.3V 针5(GND)→GND 穿W1

M5-M8 | 右电机 | 29mm正方形
  M5 (135.5,213.5)    M6 (164.5,213.5)
  M8 (135.5,242.5)    M7 (164.5,242.5)
  → 电机轴向左(Y-)伸, 轮子装轴上, 在板外侧
  → 针1(粗红)/针6(粗黑) 动力线 穿W2 → BTS7960 M+/M-
  → 针3(A相)→GPIO12 针4(B相)→GPIO13 针2(Vcc)→3.3V 针5(GND)→GND 穿W2

=== 前万向轮 (绿色 C1-C4) =================================

C1 (260,115)  C2 (280,115)
C4 (260,135)  C3 (280,135)
  → 20mm正方形, 车头板子正前方
  → M3螺丝 + 铜柱垫高到刚好贴地 (底盘高约5cm)

=== 后万向珠 (无固定孔, 板子后边缘底面) ===================

  → 第二个万向轮, 装在板子后部(X≈30-60)的底面
  → 用网格G孔或双面胶固定, 铜柱垫高到贴地
  → 作用: 防重心偏后导致车尾下坐/车头翘起

=== BTS7960 驱动板 (紫色 B1-B4) =========================

B1 (57.5,42.5)   B2 (102.5,42.5)
B4 (57.5,77.5)   B3 (102.5,77.5)
  → 45×35mm矩形, M3铜柱架高
  → B+/B- 接电池(经开关)
  → M+/M- 接左右电机动力线(经W1/W2)
  → R_EN,L_EN → VCC拉高 (常使能)
  → R_PWM,L_PWM → ESP32 GPIO 25,26,32,33
  → GND → ESP32 GND (共地!)

=== ESP32 (橙色 E1-E2) ==================================

E1 (197.5,60)   E2 (242.5,60)
  → 2个M3铜柱, ESP32平放
  → USB线 穿U1 → 树莓派 (/dev/ttyUSB0)
  → GPIO 25,26 → BTS7960 左电机R/L_PWM
  → GPIO 32,33 → BTS7960 右电机R/L_PWM
  → GPIO 27,14 → 左编码器 A,B (经W1)
  → GPIO 4,13 → 右编码器 A,B (经W2)
  → GPIO 21(SDA),22(SCL) → MPU6050 (双面胶贴底盘)
  → GPIO 34 → 电池分压(10kΩ+1kΩ) → 电池正
  → Vin → 降压模块2 的5V输出

=== 激光雷达 (红色 L1-L4) =================================

L1 (150,110)  L2 (180,110)
L4 (150,140)  L3 (180,140)
  → 30mm正方形, M3铜柱架高
  → USB线 穿U2 → 树莓派 (/dev/ttyUSB1)

=== 走线孔 (青色 W1-W3, 10mm直径) =======================

W1 (150,40)   → 左电机动力线+编码器线穿到上层
W2 (150,210)  → 右电机动力线+编码器线穿到上层
W3 (80,200)   → 电源线(电池→降压模块→ESP32/树莓派)

=== USB穿线孔 (橙色 U1-U3, 15mm直径) ====================

U1 (40,120)   → ESP32 USB线 穿到上层 → 树莓派
U2 (260,200)  → 激光雷达 USB线 穿到上层 → 树莓派
U3 (40,200)   → 备用

=== 扎带固定槽 (灰色 Z1-Z4, 8×4mm) =====================

Z1 (100,50)   → 左电机线束固定
Z2 (100,90)   → BTS7960 信号线束固定
Z3 (200,150)  → ESP32 信号线束固定
Z4 (230,80)   → 雷达USB线固定

=== 电池绑带槽 (红色 S1-S2, 15×110mm切穿) ==============

S1 (70→85, 70→180)   → 魔术贴穿过, 绑电池
S2 (120→135, 70→180) → 同上

=== 扩展网格孔 (灰色 G, 5mm直径) ========================

左区 X=30,50 Y=40-190 (2列×6行, 跳过50,40)
中区 X=190,210,230 Y=100-190 (3列×4行)
右区 X=240,260,280 Y=40-100 (3列×3行)
→ 以后加模块用, M3螺丝

=== MPU6050 IMU (无固定孔, 双面胶贴) ====================

位置: ESP32 旁边, 底盘前端上方
接线: VCC→ESP32 3.3V  GND→GND  SDA→GPIO21  SCL→GPIO22

=== 树莓派 (无固定孔, 放底盘上层) =======================

位置: 板子后半(电池上方或旁边), 双面胶/魔术贴
接线: USB1←ESP32  USB2←激光雷达  供电←降压模块1(5V)
WiFi → PC (ROS Master)
