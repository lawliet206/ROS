# 视觉+雷达融合人体跟随 — 设计规格

日期: 2026-08-03
状态: 已批准（方案 A）

## 1. 目标

在现有激光人体跟随（`laser_follower.py`）基础上，引入视觉追踪，实现：

- **方向（角度）由视觉确定**：USB 摄像头装于 J1900 车载电脑，视频推流到 PC，PC 运行 YOLOv8n 检测人，取画面最中央的人，换算为相对机器人正前方的偏角
- **位置（距离）由雷达确定**：S9 激光雷达（39点/帧，角度分辨率仅 ~9.2°，距离较准）聚类 + 人体宽度约束取最近人体簇的距离
- **融合控制器**：角度=视觉，距离=雷达，直接发布 `/cmd_vel` 驱动小车跟随
- **视觉丢失处理**：小车左右摇摆 ±60° 搜索人体，一整轮找不到则原地停止

## 2. 背景与动机

| 传感器 | 优势 | 劣势 |
|--------|------|------|
| S9 雷达 | 距离准、360°、不受光照影响 | 角度分辨率仅 ~9.2°（39点/帧），方向判断粗 |
| 摄像头 | 角度精细（±2~3°） | 无距离、受光照/遮挡影响、计算量大 |

分工：视觉定方向（精度要求高），雷达定距离（精度要求高），互补。

## 3. 系统架构（方案 A — 已批准）

```
┌─ J1900 (车载, 算力弱) ─────────────┐      ┌─ PC (ROS Master, 算力强) ────────────────┐
│ usb_cam ──▶ /image_raw/compressed ─┼─WiFi─▶│ person_detector.py                       │
│ (JPEG压缩推流, ~1-2Mbps)           │  (ROS) │   YOLOv8n → 最中央人框 → 角度换算        │
│                                    │        │   ▶ /person_angle (Float32 弧度)        │
│ s9_lidar_driver ▶ /scan            ┼───────▶│   ▶ /person_visible (Bool)              │
└────────────────────────────────────┘        │ vision_follower.py (融合控制器)         │
                                              │   ▶ /cmd_vel                            │
                                              └─────────────────────────────────────────┘
```

- J1900 只做两件轻量事：摄像头采集压缩（`usb_cam`）+ 雷达驱动（现有）
- PC 上运行两个新 Python 节点：`person_detector.py`（检测）+ `vision_follower.py`（融合控制器）
- 两节点独立：相机断流时仍可单独调试雷达跟随逻辑

## 4. 话题接口

| 话题 | 类型 | 方向 | 说明 |
|------|------|------|------|
| `/image_raw/compressed` | `sensor_msgs/CompressedImage` | J1900 → PC | 摄像头 JPEG 流 |
| `/person_angle` | `std_msgs/Float32` | 检测节点 → 融合 | 人相对机器人正前方的偏角（弧度，左正） |
| `/person_visible` | `std_msgs/Bool` | 检测节点 → 融合 | 当前帧是否检测到人 |
| `/person_overlay` | `sensor_msgs/CompressedImage` | 检测节点 | 带检测框可视化（调试用） |
| `/scan` | `LaserScan` | 雷达 → 融合 | 现有 |
| `/cmd_vel` | `Twist` | 融合 → 底盘 | 现有 |

## 5. 角度换算（视觉）

```
角度 = (图像中心x − 框中心x) × (HFOV / 图像宽度)   <!-- 左正右负: 偏左为正角 -->
```

- 摄像头朝前，光轴与雷达 0° 平行（安装时对准）
- HFOV 默认 60°，实施时用 `usb_cam` 发布的 `camera_info` 实测校准，走 rosparam `~hfov`
- 例：640 宽图像，框中心 x=400（偏右 80px）→ 角度 = (320−400) × (60°/640) = **-7.5°**（人偏右，负角 → 右转）
- 检测帧率 ~10-15 FPS（YOLOv8n CPU），端到端延迟 100-300ms，由融合端 EMA 平滑吸收

## 6. 融合控制逻辑（vision_follower.py）

改造现有 `laser_follower.py`：

**保留**：聚类、人体宽度约束 (0.1~0.55m)、EMA 平滑、连续锁定检测、PD 控制、参数化。
**改变**：角度来源从雷达簇质心 → 视觉 `/person_angle`。

### 状态机（4 态）

```
[跟随] ──视觉连续丢失N帧──▶ [搜索] ──找到人──▶ [跟随]
                                  │
                                  └──摇摆±60°一整轮无果──▶ [停止]
```

1. **跟随态**：`angle = /person_angle`（EMA），`dist = 雷达最近人体簇距离`；若雷达也丢失，只旋转对准不前进
2. **搜索态**：视觉连续丢失 N 帧（默认 5）→ 向一侧旋转至 +60°，再反向扫至 -60°；扫描期间每帧检测，`person_visible=true` 立即回跟随态并锁定
3. **停止态**：左右各扫 60°（总旋转 ~120°）未发现 → 停车 + log "目标丢失，已停车"；视觉恢复可见即重新进入跟随

### 参数（rosparam）

| 参数 | 默认 | 说明 |
|------|------|------|
| `~target_dist` | 1.0 | 目标距离 (m) |
| `~max_linear` | 0.5 | 最大线速度 (m/s) |
| `~max_angular` | 0.8 | 最大角速度 (rad/s) |
| `~min_dist` / `~max_dist` | 0.30 / 5.0 | 雷达有效距离 (m) |
| `~cluster_tol` | 0.15 | 聚类阈值 (m) |
| `~min_points` | 5 | 簇最小点数 |
| `~min_body_width` / `~max_body_width` | 0.1 / 0.55 | 人体宽度约束 (m) |
| `~min_lock_frames` | 3 | 锁定所需连续帧数 |
| `~lost_frames` | 5 | 进入搜索态所需连续丢失帧数 |
| `~search_sweep` | 60.0 | 搜索摇摆幅度（度，双向） |
| `~search_angular` | 0.6 | 搜索旋转角速度 (rad/s) |
| `~hfov` | 60.0 | 摄像头水平视场角（度） |

## 7. 检测节点逻辑（person_detector.py）

- 订阅 `/image_raw/compressed` → cv2 解码 → YOLOv8n 推理（`YOLO("yolov8n.pt")`, `conf=0.4`, 仅 class=0 person）
- 多框时选画面最中央（|框中心x − 图像中心x| 最小）
- 无框 → 发布 `person_visible=false`（角度保持上一帧）
- 模型权重首次运行自动下载（~6MB）
- 发布 `/person_overlay`（画框 + 中心十字线）供 rqt_image_view 调试

### 参数（rosparam）

| 参数 | 默认 | 说明 |
|------|------|------|
| `~image_topic` | `/image_raw/compressed` | 输入图像话题 |
| `~conf` | 0.4 | 检测置信度阈值 |
| `~hfov` | 60.0 | 水平视场角（度） |
| `~publish_overlay` | true | 是否发布可视化 |

## 8. 启动与部署

- **新增** `follow_vision.launch`（PC 端一键启动：检测 + 融合节点，可选启动雷达）
- J1900 端：`sudo apt install ros-noetic-usb-cam` + 现有 bringup（雷达 + 摄像头）
- 摄像头推流走 ROS 原生 `image_transport` 压缩（`compressed_image_transport` 包），不引入 RTSP/GStreamer 第二套系统

## 9. 误差与鲁棒性

- 视觉角度误差 ±2~3°（框中心估计），远优于雷达 ±9.2°
- 雷达距离误差保持现有水平（宽度约束过滤非人目标）
- 视觉/雷达目标短暂不一致时：以锁定连续性为准，EMA 平滑防抖
- 视觉丢失 → 搜索态；雷达丢失 → 只转不前进；双丢失 → 停止

## 10. 验证方式

1. **静态角度验证**：人站车前不同方位，对比视觉角度与雷达簇角度，误差 < 5°
2. **跟随测试**：人走动，小车保持 1m 跟随
3. **搜索测试**：人走出画面 → 摇摆 ±60° → 找到恢复 / 找不到停车

## 11. 明确不做（YAGNI）

- 不做多人身份跟踪（ReID）/ 卡尔曼目标跟踪 —— 选最中央人即可
- 不做视觉测距 —— 距离全由雷达负责
- 不引入 RTSP/GStreamer 推流
- 不做 J1900 本地推理 —— 算力不够，推流到 PC
